## 🌐 Quick Start

DPSE runs 100% locally in your browser. No database, no backend, no APIs, and **strictly zero hardware** (no Arduino, ESP32, or servos).

### Starting the Application:
1. Double-click **`start-dpse.bat`** (or open a terminal and run `npm run dev`).
2. Open your browser at **`http://localhost:3000`**.
